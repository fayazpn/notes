# Solana Commands
- `solana-keygen new`  - Create wallet and give seed phrase. Stores private key locally in the machine.
- `solana config get`  - Gives the config details
-  `solana config set --url mainnet-beta` -  Change the network
-  `solana airdrop` - get funds in the testnet - funds goto default wallet address if no address provided
