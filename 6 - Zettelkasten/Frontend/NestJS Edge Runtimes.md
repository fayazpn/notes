# NestJS Edge Runtimes

- These are cluster of CDN computers spread across the regions
- Before they only server static files
- Now we are able to execute some code in these computers called edge functions
- So when a user goes to a website, it is taken to a closest edge server where we can perform preliminary logic, such as auth, ip address etc
- These computers are very light, so they don't have full version of the nodejs run time
