# Union & Intersection Types

- **Union Types** ->  `|` signifies that it can belong to one or the other like the `OR` 
- **Intersection Types** ->  `&` signifies that it should belong to one and the other like the `AND` 
- **Type Guards** - as the *union type* accepts more than what is allowed to be accepted, code base tends to be error prone, hence we use type guards to separate out the chunks and handle them separately 
- **Discriminated Union** - use an indicator to derive the whole shape of the tuple or data structure
- intersection types are rare but happens to see at times like `Object.assign`
