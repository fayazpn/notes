# Rust Fundamentals - Basics

**Memory Safety and Zero-const Abstractions** - Devs are able to write fast and safe code due to its ownership model and borrow checker which ensure memory safety at compile time,  preventing common bugs like bull pointer de-references and data races.

**Concurrent and Safe multi-threading** - Ownership system enables developers to write concurrent code. It prevents data races at compile time.

**Ergonomics and Developer Experience** -*Cargo* is dependency manager.

**Common Commands** - 
`cargo new hello_world` -  inits a new Rust project
- *main.rs* - where code lives
- *Cargo.toml* - additional packages goes here
