# Go Fundamentals - Operators

`+` can be used for addition and used to join the strings together

**Bitwise operations**
- `--` : Reduce a number by 1
- `++`: Increase a number by 1
- `+=`: Add and assign
- `-=`: Subtract and assign

**Logical Operators**
- `&&` - if both left and right are true
- `||` - True if one or both of left and right are true
- `!` - Works only on single value, returns *true* of *false*

**Zero values**
- bool - false
- Numbers (int and float) - 0
- String - ""
- pointers, functions, interfaces, slices, channels, and maps - nil
