# Webservers

There are 2 main popular web servers
- Nginx
	- Web server
	- Reverse Proxy
	- Forward
- Apache
	- Has similar features to Nginx
	- Works right out of the box with Php & Laravel
- We need web server to route the request to a application like db, node app or another server
- Nginx is faster to implement than we doing the same with node

`sudo apt install nginx` - to install
`sudo service nginx start` - to start

After this if we visit the ip, we get the NGINX server
