- To reason code easily, we should encapsulate it, one way is to store function wit associated object (commonly used paradigm we don't have to search functionality in the entire codebase)
- Add properties to object with dot notation
- **Object.create(null)** - is a function which returns an empty object, but this gives fine grain control compared to other forms of init objects
- passing a object with methods as properties to the **Object.create** function, it will pass a reference to that passed object to every new object created (we achieve not duplicating methods that is required in every object) (new objects __proto__ will point to the the object that is passed in **Object.create**)
- When it tries to find a function in the original object, if not found, it will look into the object that is passed into the **Object.create** method
- It just create a intimate link (reference)
- When we pass object with methods and properties in **Object.create** the init objects proto property points to the passed object, when new objects are created (init), proto property of it points here, when it does not find something in the OG object, it looks up the **proto** property
- proto property is created with **Object.create** method
