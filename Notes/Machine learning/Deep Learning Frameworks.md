# Deep Learning Frameworks

Map: [[Maps/Machine learning|Machine learning]]

## Summary

Frameworks such as PyTorch and TensorFlow provide tools for building and training neural networks.

## Key points

- PyTorch provides tensor operations and automatic differentiation
- TensorFlow and Keras provide model-building and deployment tooling
- Automatic differentiation computes gradients for supported operations; custom operations may need custom gradient definitions
- Choose CPU or accelerator execution based on the workload, hardware, and measurements
