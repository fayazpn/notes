# Supervised Learning Basics

Map: [[Maps/Machine learning|Machine learning]]

## Summary

Learning a mapping from inputs to known labels/outputs - the most common ML paradigm, covering classification and regression.

## Key points

- Classification predicts a category (spam/not spam); regression predicts a continuous number (price)
- Common baseline algorithms: linear/logistic regression, decision trees, k-nearest neighbors
- Always benchmark against a trivial baseline (e.g. predict the majority class) to know if a model is actually adding value
- The bias-variance tradeoff - see [[Notes/Machine learning/Overfitting and Regularization|Overfitting and Regularization]]
