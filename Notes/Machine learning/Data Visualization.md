# Data Visualization

Map: [[Maps/Machine learning|Machine learning]]

## Summary

Communicating patterns in data visually, primarily with matplotlib and seaborn.

## Key points

- matplotlib is the low-level base; seaborn adds statistical plots with less code
- Match chart type to the question: histograms for distribution, scatter for relationships, line for trends over time
- Always label axes and title a chart meant for someone else to read
- `plt.subplots()` for multi-panel comparisons
