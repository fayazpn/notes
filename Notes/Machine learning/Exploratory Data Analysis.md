# Exploratory Data Analysis

Map: [[Maps/Machine learning|Machine learning]]

## Summary

The systematic first pass over a dataset - summarizing, visualizing, and questioning it before modeling.

## Key points

- `.describe()`, `.info()`, `.value_counts()` give a fast first read of a dataset
- Correlation matrices/heatmaps surface relationships between numeric features
- EDA should generate hypotheses, not just pretty charts - always ask 'so what?' of every chart
- Class imbalance and skewed distributions discovered here shape modeling decisions later

## Practice

- [ ] Generate a correlation heatmap for a dataset's numeric columns
- [ ] Summarize a dataset's shape, types, and missingness in a short written report
- [ ] Identify and describe a class imbalance in a target column
