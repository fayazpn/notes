# Natural Language Processing Basics

Map: [[Maps/Machine learning|Machine learning]]

## Summary

Techniques for turning raw text into structured data a model can learn from, and modeling language itself.

## Key points

- Tokenization splits text into words/subwords; stopword removal and lemmatization clean it further
- Bag-of-words / TF-IDF represent text as sparse numeric vectors for classical ML
- Word embeddings (Word2Vec, GloVe) and modern transformer embeddings capture semantic meaning densely
- Compare pretrained models with a simple task-specific baseline using held-out evaluation data
