# Solana overview

Map: [[Maps/Blockchain|Blockchain]]

## Summary

Solana applications use programs, accounts, instructions, and transactions. Learn those data and execution concepts before relying on performance or consensus summaries.

## Key points

- Accounts store state and program-related data; instructions name the program and accounts involved.
- A transaction groups authorized instructions for execution.
- Throughput figures need a date, workload, and measurement method; a headline TPS number is not a universal application guarantee.
- The original Proof of History design and protocol upgrades should be studied with their version context.
