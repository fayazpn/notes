# Blockchain basics

Map: [[Maps/Blockchain|Blockchain]]

## Summary

A blockchain links blocks of records cryptographically. A network's validation and consensus rules determine which history participants accept.

## Key points

- A hash link makes changes to earlier data detectable; consensus addresses agreement on the accepted history.
- Permissionless participation and permissioned validator membership have different trust assumptions.
- Replication can reduce some failure risks, but does not make data automatically true or remove every failure point.
- Bitcoin's proof-of-work design uses accumulated work and explicit assumptions about adversarial mining power; attacks are not “impossible.”
