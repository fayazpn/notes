# Solana CLI reference

Map: [[Maps/Blockchain|Blockchain]]

## Summary

Inspect the configured network and keypair before using commands that generate keys, request test funds, or submit transactions.

## Key points

- `solana config get` shows the current configuration.
- `solana-keygen new` creates a local keypair and recovery material. Keep that material out of notes and version control.
- Airdrops are a development/test-network facility, not a way to obtain mainnet funds.
- Network names, installation instructions, and supported flags should be checked against the installed CLI version.
