# Double spending

Map: [[Maps/Blockchain|Blockchain]]

## Summary

Double spending means attempting to spend the same spendable funds in conflicting transactions.

## Key points

- Digital messages can be copied, so a signature alone does not decide which conflicting spend should be accepted.
- A ledger must establish and enforce an accepted ordering or state transition.
- Confirmation/finality assumptions determine when applications treat an accepted transaction as settled.
