# Smart contracts

Map: [[Maps/Blockchain|Blockchain]]

## Summary

A smart contract is program logic executed under a blockchain's rules to read or change on-chain state.

## Key points

- Execution follows program logic and the chain's authorization rules; correctness still depends on the code and its inputs.
- Fungible tokens represent interchangeable units within a token system. Non-fungible token identifiers distinguish items.
- A token does not by itself guarantee the quality or exclusivity of linked off-chain content.
- Applications and governance systems may combine contracts with frontends, services, external data, and human decisions; they are not automatically fully autonomous.
