# Lists

Map: [[Maps/Python|Python]]

## Summary

Ordered, mutable collections that can hold mixed types. The most commonly used Python data structure.

## Key points

- Mutable - methods like `.append()`, `.sort()` modify in place
- Slicing works the same as strings: `lst[1:3]`
- List vs tuple: use a list when the collection will change
- Shallow vs deep copy matters for nested lists (`copy` module)
