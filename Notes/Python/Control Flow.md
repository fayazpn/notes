# Control Flow

Map: [[Maps/Python|Python]]

## Summary

Directing program execution with `if`/`elif`/`else`, and Python 3.10+ `match` statements.

## Key points

- Truthiness: empty collections, `0`, `None`, `''` are falsy
- Ternary expression: `x if condition else y`
- `match`/`case` (structural pattern matching) as an alternative to long if/elif chains
- Walrus operator `:=` lets you assign inside a condition
