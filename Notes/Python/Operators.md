# Operators

Map: [[Maps/Python|Python]]

## Summary

Symbols that perform operations on values: arithmetic, comparison, logical, bitwise, and assignment.

## Key points

- Arithmetic: `+ - * / // % **`
- Comparison chains: `1 < x < 10` is valid Python
- Logical short-circuiting: `and`/`or` return operand values, not just True/False
- Bitwise: `& | ^ ~ << >>`
