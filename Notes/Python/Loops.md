# Loops

Map: [[Maps/Python|Python]]

## Summary

Repeating code with `for` (iterates over a sequence) and `while` (runs until a condition is false).

## Key points

- `for` loops iterate over any iterable - see [[Notes/Python/Iterators|Iterators]]
- `break`, `continue`, and the lesser-known `for...else` clause
- `enumerate()` and `zip()` are the idiomatic way to loop with index or in parallel
- Avoid mutating a list while iterating over it
