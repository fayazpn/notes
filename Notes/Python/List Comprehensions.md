# List Comprehensions

Map: [[Maps/Python|Python]]

## Summary

Compact syntax for building lists: `[expr for item in iterable if condition]`.

## Key points

- Also exist for dicts `{k: v for ...}` and sets `{x for ...}`
- Nesting is possible but hurts readability past 2 levels
- Related to [[Notes/Python/Generators|Generators]] — swap `[]` for `()` to get a generator expression
