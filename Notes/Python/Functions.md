# Functions

Map: [[Maps/Python|Python]]

## Summary

Reusable blocks of code defined with `def`. Support default args, `*args`, `**kwargs`, and return values.

## Key points

- First-class objects — can be passed around, stored in variables, returned from other functions
- Enable [[Notes/Python/Closures|Closures]] and [[Notes/Python/Decorators|Decorators]]
- Scope rules: local vs global vs enclosing (LEGB)
