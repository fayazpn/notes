# Strings

Map: [[Maps/Python|Python]]

## Summary

Immutable sequences of Unicode characters, with extensive built-in methods for manipulation.

## Key points

- Strings are immutable - every 'modification' returns a new string
- f-strings (`f'{x}'`) are the modern, preferred formatting method
- Common methods: `.split()`, `.join()`, `.strip()`, `.replace()`, `.format()`
- Slicing: `s[start:stop:step]`
