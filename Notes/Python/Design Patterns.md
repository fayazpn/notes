# Design Patterns

Map: [[Maps/Python|Python]]

## Summary

Reusable solutions to common software design problems, adapted to Python's dynamic style.

## Key points

- Singleton - often replaced in Python by a module-level instance
- Factory - a function/classmethod that returns different subclass instances based on input
- Observer - objects subscribe to and react to events (basis of GUI/event systems)
- Strategy - swap an algorithm at runtime by passing in a function or class
